# MyBot

This repository only holds the released versions of MyBot: the Windows installer and the Linux AppImage, under
[Releases](../../releases). The installed application updates itself from here.

## Install

- **Windows**: download `MyBot-Setup-X.Y.Z.exe` from the latest release and run it.
- **Linux**: download the `.AppImage` from the latest release, make it executable (`chmod +x`), then run it.

## Activation

From version 12.0.3, MyBot needs an activation key. On the first start, the activation window shows the ID of your
PC: click **Copy**, send it to get your key, then paste the key and click **Activate**. A key works on that PC only.
