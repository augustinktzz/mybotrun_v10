The OpenCV engine of the bot can now answer the image searches of the whole bot: when a template folder of the DLL has a PNG mirror in imgcv\<same path>\, the searches of that folder (findImage, findMultiple, QuickMIS, FindImageInPlace...) are served by the bot's own engine, unchanged for the 400 call sites. Same for the text: a glyph folder imgcv\OCR\<font>\ makes the bot read that font itself.
A shadow.txt file in such a folder keeps the DLL in charge and only logs the OpenCV result ("CV Search", "CV shadow", "CV ocr" lines), which is how each folder is validated before the switch. Two folders ship in that mode: the resource icons of the builder menu and the main screen counters font (coc-ms).
Own wall templates moved to imgcv\own\Walls\<level>\ (the imgcv\Walls\ name is reserved for a mirror of the DLL wall templates).
