Speed: measuring the village (ZoomOut) is faster. The bot walked through the stone and tree reference images one by one on every zoom out, and read the folder from disk each time, although the scenery of a village never changes: on a real log the tree was always the fifth file tried, which cost 0.74 s against 0.22 s for the stone found on the first try. The folder is now read once and the image that matched last time is tried first, so the four useless searches are gone. The list is only reordered, never shortened: if the scenery really changes the bot simply carries on through the other images as before. New reference images need a bot restart to be picked up.
